# Collector 테스트 구조

테스트 종류가 실제 구현과 섞여 보이지 않도록 목적별로 구분한다.

- `unit/`: 공개된 type과 함수, HTTP route를 통해 작은 기능을 빠르게 확인하는 단위 테스트
- `testdata/`: 단위 테스트가 읽는 저장 HTML과 JSON
- `integration/`: 실제 판매처나 다른 서비스에 접속하는 통합 테스트

이 프로젝트에서는 실제 코드와 테스트 파일을 눈으로 쉽게 구분할 수 있도록 모든 `*_test.go`를 `tests/` 아래에 둔다. 내부 비공개 함수를 직접 호출하지 않고 공개된 함수나 HTTP route를 통해 동작을 확인한다.

`integration/` 테스트는 기본 실행에서 외부 요청을 보내지 않는다. 필요한 환경변수를 명시한 경우에만 실제 외부 서비스에 접속한다.
