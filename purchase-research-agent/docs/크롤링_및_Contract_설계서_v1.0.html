§ 1

시스템 구성 개요

purchase-research-agent(FastAPI, 포트 8012)는 두 쇼핑몰에서 상품 데이터를 수집하고 JSON Schema로 데이터 품질을 검증한 뒤 purchase-research-backend(Spring, MySQL)로 전송한다. 현재 운영 중인 크롤러는 ABC마트와 29CM 두 종류이며, 수집 방식이 서로 달라 사이트별 독립 계약(Contract)을 정의한다.

⚠

카테고리 크롤링 미지원. 29CM 검색 페이지(www.29cm.co.kr/search)는 Next.js SSR 구조로, 필터링(카테고리, 가격, 색상)이 모두 서버 내부에서 처리된다. 클라이언트 측에서 접근 가능한 카테고리 API가 없어 현재 구현되지 않았다. crawl_category()는 빈 목록과 오류 메시지를 반환한다.

ℹ

color · style_code 항상 빈 문자열. 29CM BFF API 응답(itemInfo)에는 카드 단위 색상·스타일 코드가 포함되지 않는다. 두 필드는 Contract 규격에서 maxLength: 0으로 명시적으로 고정된다.

Contract 규칙 — v1-29cm

파일 위치: contracts/collector/v1-29cm/29cm-crawl-item.schema.json  ·  Draft 2020-12  ·  additionalProperties: false

필드 타입 제약 조건 설명
site string const: "29cm" 사이트 식별자 고정값
source_product_id string minLen:1 maxLen:50 itemId(숫자)를 str() 변환
title string minLen:1 maxLen:300 itemInfo.productName
brand string maxLen:100 null이면 빈 문자열
price string ^$|^[0-9,]+원$ itemInfo.sellPrice → "{n,nnn}원"
price_original string ^$|^[0-9,]+원$ null이면 빈 문자열
discount_percent integer|null 0 ≤ n ≤ 100 saleRate → round() 정수
image_url string maxLen:500 itemInfo.thumbnailUrl
color string maxLen: 0 (항상 빈 문자열) BFF API가 카드 단위 색상 미제공
style_code string maxLen: 0 (항상 빈 문자열) BFF API가 스타일 코드 미제공
link string pattern (아래) itemUrl.webLink
"link" pattern: ^https://(www|product)\.29cm\.co\.kr/.*$ ├─ www.29cm.co.kr/search/... (이전 URL 형식) └─ product.29cm.co.kr/catalog/{itemId} (현재 실제 응답)
ℹ

v1-abcmart와의 차이. 필수 11개 필드는 동일하나 color와 style_code에 maxLength: 0 제약이 추가된다. 선택 필드(review_count, reviews[], options)가 없다. link 패턴 도메인이 다르다(a-rt.com vs 29cm.co.kr).

§ 6

병렬 실행 구조

CrawlerService는 asyncio.gather()를 통해 여러 사이트를 동시에 크롤링한다. 각 SiteCrawler는 독립 async 코루틴으로 실행되며 서로를 블로킹하지 않는다.

ASYNCIO.GATHER — 병렬 실행 흐름
asyncio
.gather()
ABC마트
crawl_category()
29CM
crawl()
결과 병합
validate_items()
실측: ABC마트 30개 + 29CM 30개  =  5.95s (순차 실행 대비 약 2배 단축)
# CrawlerService.search_items() — 다중 사이트 병렬 (abc_products, abc_errors), (cm_products, cm_errors) = await asyncio.gather( AbcMartCrawler().crawl_category("구두_남성", max_items=30), Cm29Crawler().crawl("구두", max_items=30), )
구분동작 방식딜레이 정책
ABC마트 Crawl4AI + BeautifulSoup HTML 파싱 (페이지당 delay_before_return_html=2.0) 페이지 간 asyncio.sleep(1)
29CM httpx POST JSON API (브라우저 없음, 단순 HTTP) 페이지 간 asyncio.sleep(1)
DetailFetcher ABC마트 내부 API (리뷰 + 옵션) API 호출 간 asyncio.sleep(5.0)
