§ 1

시스템 구성 개요

purchase-research-agent(FastAPI, 포트 8012)는 두 쇼핑몰에서 상품·리뷰·옵션 데이터를 수집하고 JSON Schema로 품질을 검증한다. v2.0부터 상세 정보 수집(attach_details)이 양쪽 모두 지원되며, app/normalizer.py가 두 사이트 출력을 통일 구조(Unified)로 변환한다.
