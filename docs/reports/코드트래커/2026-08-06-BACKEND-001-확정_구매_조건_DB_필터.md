## 발생 문제와 원인

10만 원 이하 조건인데 119,280원 상품이 반환됐다. 기존 조사 검색은 `productType`과
`merchant`만 사용하고 나머지 확인 조건을 기존 후보 검색에 전달하지 않았다.

## 해결

판매처 상품의 최신 offer만 선택해 가격/통화/재고를 검사하고 같은 snapshot의 재고 있는
옵션에서 사이즈와 색상을 검사한다. 최신 snapshot에 옵션이 없으면 오래된 옵션을 현재 정보로
사용하지 않는다.
