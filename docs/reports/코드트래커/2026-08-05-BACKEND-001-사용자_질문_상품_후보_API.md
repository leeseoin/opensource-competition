## 배경과 범위

Next.js와 향후 MCP Server가 같은 계약으로 PostgreSQL 상품을 조회할 수 있도록 원본 구매
질문과 명시적 DB 검색어를 분리한 후보 API를 기존 상품 검색 서비스 위에 추가했다.

## 발생 문제와 원인

기존 `GET /internal/v1/products`는 상품 검색에는 충분하지만 사용자의 원본 질문을 보존하지
않아 Next.js와 향후 MCP 응답을 같은 조사 문맥에 연결하기 어려웠다.

## 해결

기존 repository와 `ProductQueryService`를 재사용하는 얇은 후보 use case를 추가했다. 자연어
해석을 Product Backend가 추측하지 않고 `question`과 `query`를 분리해 호출자가 명시하도록 했다.
