## 발생 문제와 원인

- 공식 스킬 검사 script가 로컬 Python의 `ModuleNotFoundError: yaml` 때문에 실행되지
  않았다.
- 첫 문서 검사에서 zsh 특수 변수 `path`를 반복 변수로 사용해 명령 검색 경로가
  덮어써졌다.

## 해결

- 프로젝트 Python 의존성을 임의로 추가하지 않고 Ruby 기본 YAML parser와 필수 필드
  검사로 스킬 파일 구조를 점검했다.
- shell 반복 변수 이름을 `doc_file`로 바꾸고 문서 동기화 검사를 다시 실행했다.
