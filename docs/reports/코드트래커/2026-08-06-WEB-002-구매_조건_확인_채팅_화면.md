## 발생 문제와 원인

Next.js 16은 `route.ts`의 HTTP method 외 export를 허용하지 않았고 기존 Google font 사용은
오프라인 production build를 실패시켰다. Turbopack production build는 로그 없이 멈췄다.

## 해결

Route 진입점과 테스트 가능한 handler를 분리했다. system font fallback으로 외부 다운로드를
제거하고 production build script는 검증된 webpack 경로로 고정했다.

## 검증

- `cd frontend/purchase-web && npm run lint`: 통과
- `cd frontend/purchase-web && npm run build`: 통과, 정적 `/chat`과 동적 research API 생성
- `npm audit --omit=dev --offline`: production 의존성 취약점 0건
- 자동 browser E2E: 연결 가능한 browser가 없어 미검증
