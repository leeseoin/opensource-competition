## 배경과 범위

Next.js Agent Gateway가 실행한 Codex CLI의 OAuth token과 refresh token이 폐기됐을 때
child process stderr가 browser 응답에 그대로 포함됐다. stderr에는 Plugin 규칙과 실행 오류
원문이 포함될 수 있어 사용자 안내와 server 진단 경계를 분리했다. 빈 `.env` 값이 실행 기본값을
무력화한 문제도 같은 실행 설정 경계에서 수정했다.

## 발생 문제와 원인

- 증상: `/chat`에서 폐기된 Codex OAuth token의 401 로그와 Plugin prompt가 긴 오류 메시지로
  표시됐다. `.env`에 값이 없는 경우 Codex 실행과 MCP의 Product Backend 연결도 실패했다.
- 원인: Codex 비정상 종료 시 stderr 마지막 4,000자를 사용자 오류에 결합했고, null만 기본값으로
  처리하는 연산자가 빈 문자열을 유효한 설정으로 간주했다.

## 해결

인증 오류 지표를 server에서 분류해 사용자가 실행할 `codex logout` 및 `codex login`만
안내한다. 다른 실행 실패도 원문 stderr를 browser에 반환하지 않는다. 실행 파일과 Product
Backend 주소는 공백을 제거한 뒤 값이 없으면 안전한 로컬 기본값을 사용한다.
