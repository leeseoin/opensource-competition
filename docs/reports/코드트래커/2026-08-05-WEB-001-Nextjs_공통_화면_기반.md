Next.js 기본 생성 화면을 Purchase Research Agent의 공개 랜딩 화면으로 교체하고,
Figma V2 디자인에서 사용하는 전역 서체, 색상, 이미지와 반응형 화면 기반을 적용했다.

## 발생 문제와 원인

Figma 디자인의 원격 asset URL은 일정 기간 후 만료되고 고정 데스크톱 좌표는 모바일 화면에 그대로 적용할 수 없었다.

## 해결

상품 이미지와 아이콘을 `public`에 저장하고 CSS Module의 Grid/Flex 및 media query로 디자인을 반응형 화면으로 변환했다.
