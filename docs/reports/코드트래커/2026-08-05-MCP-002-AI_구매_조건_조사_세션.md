## 배경과 범위

Codex가 자연어 구매 질문을 임의 JSON으로 반환하지 않도록 공통 `PurchaseCondition` 계약을
정의했다. AI가 만든 조건은 바로 검색에 사용하지 않고 Spring Boot 조사 세션에 DRAFT로
저장하며, 사용자가 확인한 뒤에만 PostgreSQL 상품 검색을 허용한다.

## 발생 문제와 원인

초기 confirm 처리 안에서 상품을 즉시 검색하면 MCP 검색 도구가 사용자 확인 상태를 독립적으로
검사했다는 사실을 테스트할 수 없었다.

## 해결

조사 세션 생성, 사용자 확인과 상품 검색 API를 분리했다. 검색 시점에 DB의 세션 상태를 다시
조회하고 CONFIRMED가 아니면 `RESEARCH_SESSION_NOT_READY` 오류로 차단한다.
