## 배경과 범위

사용자가 랜딩에서 구매 질문 화면으로 이동하고 질문을 입력한 뒤, 정적 추천 후보의 가격,
재고와 출처 검증 근거를 확인하며 세 상품을 비교하는 사용자 흐름을 구현했다.

## 발생 문제와 원인

Figma MCP 참고 코드는 1440px 절대 좌표와 Tailwind class를 사용해 현재 CSS Module 구조에 직접 적용할 수 없었다.

## 해결

디자인의 색상, 서체, 상품 이미지와 정보 위계는 유지하고 Grid/Flex 기반 CSS Module로 변환했다.
질문 제출은 실제 백엔드를 호출하지 않고 화면 내 브리프만 갱신하도록 구현 범위를 분명히 제한했다.
