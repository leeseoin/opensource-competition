## 발생 문제와 원인

Figma의 고정 예시 상품을 실제 응답으로 교체하면서 browser에 Product Backend 내부 주소를
노출하지 않아야 했고, Product Backend가 꺼졌을 때 화면 요청이 무한 대기하면 안 됐다.

## 해결

Next.js server route가 서버 전용 환경변수로 Product Backend를 호출하도록 경계를 두고 5초
timeout, 400, 502와 503 응답을 구분했다. browser는 같은 출처의 route만 호출하며 화면은
Product Backend가 반환한 가격, 재고, 판매처, 이미지와 수집 시각을 표시한다.
