## 배경과 범위

색상별 판매 행이 같은 상품 카드로 반복되던 문제를 해결하고 최대 5개 상품군 안에서
사용자가 컬러와 재고 상태를 선택하도록 후보 응답과 Web 화면을 확장했다. 현재 안전한
파생 상품군은 같은 판매처, 브랜드, 상품명과 카테고리 조합을 기준으로 한다.

## 발생 문제와 원인

후보를 상품군으로 묶기 전에 3건으로 잘라 같은 상품이 반복됐고 수집 검색어가 상품
관련성처럼 강하게 반영됐다. 판매처 상세 옵션이 없어 신발 외 용량, 소재와 규격은 아직
구성할 수 없다.

## 해결

후보 pool을 먼저 넓혀 재정렬한 뒤 상품군을 묶고 대표 5개를 선정했다. 상위 상품군은
필터에서 제외된 다른 컬러 행도 다시 조회하며 요청 사이즈가 없으면 숨기지 않고 구매 불가로
표시한다.
